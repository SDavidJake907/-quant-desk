Read this before reading the map

Membership is today’s. That is correct for a live view and wrong for a backtest: a company only joins an index after it has already run. The backtest path reconstructs point-in-time membership instead.

The scale clamps. Relative strength has a long right tail, and a single name far out on it would flatten every other cell to the same tone. Values past the ends of the legend are drawn at full intensity, so the extremes are compressed — read rank, not distance, at the edges.

Relative strength describes the past year. 12-1 momentum deliberately skips the most recent month. It is the best-supported number in this system and it still says nothing about what happens next.
